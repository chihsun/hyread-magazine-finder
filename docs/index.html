資料定義與更新說明

「有收錄」指 HyRead 該館的雜誌書目列出此書名及最新發刊日期，並非即時可借閱狀態。一般版與精華版分開計算。「未列出」不代表沒有舊期刊。

發刊日期篩選以臺灣日期計算；最近 N 天包含今天，已提前上架的未來紙本刊期也會納入最近 N 天（沒有未來日期上限）。未指定圖書館時，以所有圖書館中最新的發刊日期篩選與排序；指定圖書館時，改用該館的發刊日期，無該館日期的結果在日期排序中排最後。

「隱藏沒有該本書的圖書館」只精簡畫面上的每本雜誌館藏列，並不更改收錄館數、搜尋結果或 CSV 的九館對照欄位。

書目由管理者在一般瀏覽器中人工取得，交由本機工具整理、驗證與增量合併，之後推送 GitHub 發布。由於網站的存取驗證限制，GitHub Actions 的每週 HyRead 擷取排程已取消；保留的 Actions 僅用於程式測試、選用的資料匯入與網站部署，不會自動擷取書目。「重新載入資料」僅重新讀取已發布的 JSON。

書目更新以本次核實的資料為準；若缺頁、核對未完成或來源無法取得，應標記部分核對／失敗並保留舊資料，不會因未查到就刪除原有書名。最新刊期與已核實的詳細書目連結會保留，異動歷史保留 180 天。

本次新增書名及刊期變動依「書名 × 圖書館」分別記錄；相同書名可能在多館各有一筆異動。頁面會列出書名、館別及刊期前後差異。個別雜誌已核實的詳細連結顯示於館別日期旁；沒有證據的 jid 不會猜測。

來源：九間公共圖書館的 HyRead 官方雜誌分類書單。最初資料核對截止日為 2026/09/20（含）。部分發刊日期可能是網站預告的未來刊期。
