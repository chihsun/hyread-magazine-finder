資料定義與更新說明

「有收錄」指 HyRead 該館的雜誌書目列出此書名及最新發刊日期，並非即時可借閱狀態。一般版與精華版分開計算。「未列出」不代表沒有舊期刊。

發刊日期篩選以臺灣日期計算；最近 N 天包含今天，網站預告的未來刊期只出現在「不限日期」，不會算進最近 N 天或超過 90 天。未指定圖書館時，以所有圖書館中最新的發刊日期篩選與排序；指定圖書館時，改用該館的發刊日期，無該館日期的結果在日期排序中排最後。

「隱藏沒有該本書的圖書館」只精簡畫面上的每本雜誌館藏列，並不更改收錄館數、搜尋結果或 CSV 的九館對照欄位。

本系統每週五早上 08:00（臺灣時間）執行更新，並支援管理者透過 GitHub Actions 手動執行。「重新載入資料」只讀取已發布的網站資料，不會對 HyRead 發起抓取。

每館抓取至多額外重試三次。若本次失敗，保留最後成功紀錄並顯示資料可能過期；連續三次完整核對未列出才會將書目標記為未列出。歷史變動只保留 180 天，各館最新一筆紀錄則永久保存。

來源：九間公共圖書館的 HyRead 官方雜誌分類書單。最初資料核對截止日為 2026/09/20（含）。部分發刊日期可能是網站預告的未來刊期。
